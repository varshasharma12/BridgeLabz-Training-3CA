CSS Box Model Exploration

Every HTML element is made up of content, padding, border and margin.

Box Model Layers

Margin
Border
Padding
Content

Content: Actual text or element.
Padding: Space around content.
Border: Line surrounding padding.
Margin: Space outside the border.

Default Box Sizing

With content-box, width and height apply only to the content. Padding and border are added outside the given size.

Border-Box

With border-box, padding and border are included inside the given width and height.
