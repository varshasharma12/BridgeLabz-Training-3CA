Responsive CSS Cheat Sheet

Important concepts of Responsive CSS

Filters

CSS filters can change the appearance of images.

Example: filter: grayscale(100%);

Media Queries

Media queries change the design according to screen size.

Example: @media (max-width: 700px)

Responsive Design

Responsive design makes a website work on different devices.

Example: width: 100%;

Typography

Responsive typography changes the text size according to the screen.

Example: font-size: clamp(1rem, 2vw, 1.5rem);

Flexbox

Flexbox is used to arrange elements in rows or columns.

Example: display: flex;

Grid

CSS Grid is used to create rows and columns.

Example: display: grid;
