Responsive Design

Responsive web design makes a website adjust according to the screen size. Flexbox and Grid help arrange the content, while media queries help change the layout on smaller screens.

CSS Cheat Sheet

Flexbox: Used to arrange elements.

Grid: Used for rows and columns.

Media Query: Changes layout for screen sizes.

Clamp: Creates responsive text sizes.
