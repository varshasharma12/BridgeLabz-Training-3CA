Responsive Design Principles

Core principles of responsive web design

Fluid Layouts

A fluid layout adjusts its size according to the screen.

CSS Example: width: 100%;

Flexible Media

Flexible media adjusts images and videos according to the screen.

CSS Example: max-width: 100%;

Breakpoints

Breakpoints change the layout at different screen sizes.

CSS Example: @media (max-width: 600px)
