Q1. Explain the difference between frontend, backend, and full-stack development with suitable real-world examples.
Answer- Frontend is the part of a website that users can see and use. HTML, CSS and JavaScript are mainly used for frontend.
Example: The Amazon webpage that we see is frontend.
Backend works behind the website. It handles data, login and server-side work.
Example: When we login to Amazon, the backend checks our login details.
Full-stack means working on both frontend and backend.

Q3. Describe how a browser requests and displays a web page from a web server.
Answer- The browser sends a request to the web server. The server processes it and sends the webpage back. The browser then displays the webpage.
        Browser → Server → Webpage
